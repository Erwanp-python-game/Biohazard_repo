1 create image for level title in "Biohazard\image\level"
2 create level number n with level.py placing the trigger 1 near the starting point
 else no start message impossible to move
3 create n.txt in "Biohazard\level\texts" with a text for the first trigger,
 ex: {1:"Hello"}
4 set level_start[n] and level_end[n] to the trigger number you want to start and
 end the level (example 1 and 100 at the start) in line 925 of game.py
5 fill levelD[n] in line 55 of game.py without changing the end of the list 2,0,0,5]
 (ammo and cards specific types)

remark
slanted walls are not meant to be see from both sides, when slanted only the normal
face should be seen

Editor controls:

-x for trigger placing
-a for lift
-select +/- group number then enter for group trigger
-press scroll button on mouse -> print position of the mouse
-select a wall and press * to set a code to a door
-select a wall and press left ctrl to lock a door and create a key press t to change
the color
-0 (not keypad) to place monsters/objects
-shift to choose between monsters/objects
-keypad numbers to change texture type or monster/object type
-enter to place roof
-space to switch front wall to door
-e to enter select mode
-l to place lights
-to include in a group select then change with +/- group number and press enter
-c to change second face
-a to place lift
-g to place teleport
-h to change height of wall only
-b for orientation of objects
-j to make platform, height +/-
-i to rotate flat orientation
-u sphere type (0:no,1:sphere,2:cyl, 3:inf cyl), height with p/o
-f switch top/bottom platforms
-m platform sides to place
